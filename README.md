# SpeedSpell ⚡
> **中1英単語 つまずき特訓 Webアプリ（タイパ重視・即答トレ）**

カタカナ読みや意味は分かるのに「英語のスペル（つづり）がどうしても書けない」中学1年生向けに開発された、超速反復型の英単語スペリング習得Webアプリです。

サーバー不要、外部通信不要。PC・スマートフォンのブラウザ単体で完全に動作します。

---

## 💡 本アプリの学習メソッド（なぜ短時間で書けるようになるのか？）

1. **リアルな誤答スペル（トラップ）を含む5択問題**
   * 単語全体を選ぶ形式でありながら、以下の4パターンのトラップを網羅した**5択形式**です：
     * **① カタカナ読みのローマ字**（例: `raito`, `rido`, `meiku`, `san`, `furendo`）
     * **② 似た発音の別英単語・同音異義語**（例: `write` ➔ `right`, `read` ➔ `red`/`lead`, `two` ➔ `to`/`too`, `four` ➔ `for`）
     * **③ 中1特有のミス（r/l混同、th混同）**（例: `friend` ➔ `fliend`, `play` ➔ `pray`, `grandfather` ➔ `glandfather`）
     * **④ 娘さんの手書き誤答**（例: `pearents`, `scooht`, `trhee`, `sven`, `Junuary`, `Desember`）
   * 頭文字やシルエットだけで選べないため、**「スペルの細部を瞬時に見抜く目」** が自然と育ちます。
2. **1問10秒 ＆ 「押したら進む」安心設計**
   * 制限時間は5択に合わせて**10秒**（直感でパッと見極める）。
   * PCキーボード（`1`, `2`, `3`, `4`, `5`）またはタップで回答。
   * **回答後すぐに勝手に次の問題へ進むことはありません**。正解スペル、ネイティブ音声、1行解説をじっくり確認したあと、**「次へ進む ➔」ボタン**（または画面タップ、Space、Enterキー）を押して自分のペースで進められます。
3. **未マスター（要復習）優先の自動集中出題 ＆ ボタン1本化**
   * トップ画面のスタートボタンを1つに統合。「特訓スタート」を押すだけで、**まだ3回連続正解していない単語（要復習語）が自動的に最優先で出題**されます（全問出題・10問制限なし）。
   * 全問マスター（100%）達成時は「総復習テスト」として全問からランダム出題されます。
   * 誤操作による進捗消去を防ぐため、学習記録のリセット機能は設定画面（⚙️）の折りたたみ内に安全に格納されています。
4. **まぐれ正解を許さない「3回連続正解マスター制」**
   * 1回正解しただけでは復習リストから外れません。
   * **3回連続で正解（★★★）して初めて「マスター達成」** となります。
   * 途中で1度でもミスすると容赦なく「☆☆☆ 要復習」に転落するため、うろ覚えのまま放置されるのを防ぎます。
5. **ステップアップ対応「タイピングモード（15秒）」**
   * 右上の ⚙️（歯車アイコン）から「タイピング入力モード」に切り替え可能。
   * 選択式でスペルの形を覚えたあとに、実際にキーボードで文字を打ち込んで100%書けるかテストできます（制限時間15秒・PCのEnterキーやスマホ入力両対応）。
6. **完全内蔵のネイティブ音声 ＆ 心地よい効果音**
   * ブラウザ内蔵の **Web Speech API** により、外部通信なしでネイティブ発音を再生（出題時＋正解表示時）。
   * **Web Audio API** により、ラグゼロで軽快な正解音・不正解音を自前合成。

## 🖥️ ローカルでの動作確認方法

GitHubに公開する前に、ご自身のPCや同一Wi-Fiのスマホから動作を確認できます。

### 方法1: ブラウザで直接開く（一番シンプル）
外部通信やサーバー機能を使っていないため、ファイルを直接ブラウザで開くだけで100%動作します。
* **ファイル**: `public/index.html`
* PCのファイルマネージャーから `index.html` をダブルクリック、またはブラウザにドラッグ＆ドロップしてください。
* （Linuxコマンドの場合: `xdg-open public/index.html`）

### 方法2: Pythonでローカルサーバーを起動（スマホ実機でも確認可能・推奨）
同一Wi-Fiに接続している娘さんのスマホから実機テストしたい場合に便利です。

1. **サーバーを起動**:
   ```bash
   cd /home/tomoya/anki/public
   python3 -m http.server 8000
   ```
2. **PCから確認**:
   ブラウザで `http://localhost:8000` を開きます。
3. **同一Wi-Fiのスマホから確認**:
   * PCのローカルIPアドレスを確認します（ターミナルで `hostname -I` を実行）。
   * スマホのブラウザ（SafariやChrome）で `http://<PCのIPアドレス>:8000` を開きます。
   * 例: `http://192.168.1.15:8000`

## 🚀 GitHub Pages への公開手順

`public/` フォルダの内容を自動公開する GitHub Actions の設定を組み込み済みです。

### ステップ1: 変更のコミット
```bash
cd /home/tomoya/anki
git add .
git commit -m "chore: move web files to public directory"
```

### ステップ2: GitHub でリポジトリを作成
1. ブラウザで [GitHub](https://github.com/) にログインし、右上の **「+」➔「New repository」** を開きます。
2. リポジトリ名を入力します（例: `speed-spell` または `anki`）。
3. 公開設定を **「Public」** に設定します。
4. チェックボックスはすべて外したまま、**「Create repository」** をクリックします。

### ステップ3: GitHub へプッシュ
```bash
# <YOUR_USERNAME> と <REPO_NAME> はご自身のものに置き換えてください
git remote add origin https://github.com/<YOUR_USERNAME>/<REPO_NAME>.git
git push -u origin main
```

### ステップ4: GitHub Pages の設定（Source を選択）
1. 作成したGitHubリポジトリのページで、上部メニューの **「Settings」**（歯車アイコン）をクリックします。
2. 左メニューの **「Pages」** をクリックします。
3. **「Build and deployment」** の下の **「Source」** ドロップダウンで **「GitHub Actions」** を選択します。
4. これでプッシュ時に自動的に `.github/workflows/deploy.yml` が走り、`public/` フォルダの内容が公開されます！
5. 数十秒で上部に公開URLが表示されます：
   ```
   Your site is live at https://<YOUR_USERNAME>.github.io/<REPO_NAME>/
   ```

## 📱 スマホで「本物のアプリ」として使う方法（ホーム画面追加）

本アプリは **PWA（Web App Manifest）** に対応しています。スマホのブラウザで公開URLを開き、ホーム画面に追加すると、アドレスバーのない全画面アプリとして起動できます。

### iPhone (Safari) の場合
1. Safari で GitHub Pages の URL を開きます。
2. 画面下部中央の **「共有ボタン（四角から矢印が出ているアイコン）」** をタップします。
3. メニューをスクロールし、**「ホーム画面に追加」** を選択します。
4. ホーム画面に稲妻アイコンの「SpeedSpell」が追加され、タップするとアプリとして起動します。

### Android (Chrome) の場合
1. Chrome で GitHub Pages の URL を開きます。
2. 画面右上または右下の **「メニュー（縦の3点リーダー）」** をタップします。
3. **「ホーム画面に追加」** または **「アプリをインストール」** をタップします。

アプリ右上の **歯車（⚙️）アイコン** をタップすると、新しい問題セットを追加できます。

テキストエリアに、学校のワークや教科書から単語を以下のように貼り付けるだけで完成します：

```text
pencil, 鉛筆
notebook, ノート
dictionary, 辞書
eraser, 消しゴム
textbook, 教科書
```

* カンマ区切りのテキストを貼るだけで、**トラップスペルや解説が自動生成**されます。
* 登録したセットはブラウザ内部（localStorage）に安全に保存されます。
