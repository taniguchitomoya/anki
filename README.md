# SpeedSpell ⚡
> **中学英語 つまずき特訓 Webアプリ（スペル・英日・文法穴埋め 即答トレ）**

英語に苦手意識がある中学生や学び直しの方、スペル・文法（三単現のsやbe動詞など）でつまずいてしまった生徒向けに開発された、超速反復型の英語基礎習得Webアプリです。
「中1の文法問題や基本文がスラスラ読めるようになる超コア単語153問（5ジャンル）」と、『中学英語をもう一度ひとつひとつわかりやすく。改訂版』の全21チャプターに完全対応しています。

サーバー不要、外部通信不要。PC・スマートフォン・タブレットのブラウザ単体で完全に動作します。

## 💡 本アプリの学習メソッド（なぜ短時間で身につくのか？）

1. **英単語が壊滅していても解ける「超基本」×「2〜5択形式」**
   * **日英スペル特訓（5択）**: ローマ字トラップや同音異義語、r/l混同などを網羅した誤答から本物のスペルを瞬時に見抜く。
   * **英日コア単語特訓（4択）**: 最優先の土台となる5ジャンル（基本動詞・代名詞/疑問詞・数字/曜日/月/季節・基本形容詞・身の回りの名詞）を見て直感的に日本語の意味を即答。
   * **文法穴埋め（2〜3択）**: 『中学英語をもう一度ひとつひとつわかりやすく。改訂版』のCHAPTER 01〜21に完全準拠。英文自体は超平易な単語のみで構成されているため、各章の文法ルールだけに100%集中して特訓できます。
2. **1問10秒 ＆ 「タップ選択 ➔ 決定」の誤タップ防止設計**
   * 制限時間は直感でパッと見極められる**10秒**（設定から変更可能）。
   * 選択肢をタップしたあと、下部の「決定する」ボタンを押して回答する2ステップ方式を採用。指が触れて即ミスになる誤タップを防止します（※時間切れ時は仮選択中の選択肢で自動判定）。
   * 回答後すぐに勝手に次の問題へ進むことはなく、正解・完成文、ネイティブ音声、1行解説をじっくり確認したあと、「次へ進む ➔」ボタンを押して自分のペースで進められます。
   * iPadなどのタブレット端末では、ボタンの高さ・文字サイズ・カード幅が大きく押しやすい専用レイアウトに自動最適化されます。
3. **未マスター（要復習）優先の自動集中出題 ＆ クリア済みループ防止設計**
   * トップ画面の大きな **「スタート」** ボタンを押すだけで、**まだマスターしていない問題（要復習）が自動的に最優先で出題**されます（全問出題・10問制限なし）。
   * 全問マスター（100%クリア）達成したセットは、ドロップダウンに `✅ クリア済` が表示され、メニュー画面および結果画面にクリア達成バナーが表示されます。また、結果画面では「メニューへ戻る（次のセットへ）➔」がメインボタンになるため、手癖で同じセットを無限ループしてしまうのを防ぎます。
   * プレイ画面左上の「✕ メニュー」ボタンから、セットの途中でもいつでもメニュー画面に戻ることができます（途中の回答分も記録されます）。
   * 誤操作による進捗消去を防ぐため、学習記録のリセット機能は設定画面（⚙️）の折りたたみ内に安全に格納されています。
4. **問題セットごとに設定可能なマスター条件（デフォルト3回連続・基本英日は1回正解クリア）**
   * 問題セット定義の `requiredStreak` プロパティでマスターに必要な連続正解数を指定できます（省略時のデフォルト値は `3`）。
   * スペル特訓や文法穴埋めセットは **3回連続で正解（★★★）して初めて「マスター達成」** となり、途中でミスすると「☆☆☆ 要復習」に転落します。
   * 一方、最優先の土台である **超基本単語（英日）5セットは `requiredStreak: 1`（1回正解で即マスター達成 ★）** に設定されており、テンポよくサクサク確認を進められます。
5. **ステップアップ対応「タイピングモード（15秒）」**
   * 右上の ⚙️（歯車アイコン）から「タイピング入力モード」に切り替え可能（日英スペル問題に対応）。
   * 選択式でスペルの形を覚えたあとに、実際にキーボードで文字を打ち込んで100%書けるかテストできます。
6. **完全内蔵のネイティブ音声 ＆ 心地よい効果音**
   * ブラウザ内蔵の **Web Speech API** により、外部通信なしでネイティブ発音を再生（単語問題は出題時＋正解表示時、穴埋め問題はヒントにならないよう回答後に完成英文をまるごと発音）。
   * **Web Audio API** により、ラグゼロで軽快な正解音・不正解音を自前合成。

## 📦 収録問題セット

### スペル特訓（日英）
* **🎯 基本単語２７（27問・5択／タイピング）** 【初期選択】
  * つまずきやすい最重要単語（`grandfather`, `parents`, `three`, `Sunday`, `Tuesday`, `Wednesday`, `January`, `watch`, `listen`, `make`, `money` など）のスペルを集中的に攻略する日英特訓セット。

### 超基本単語（英日・最優先の土台153問）
中1の文法問題や教科書の基本文がスラスラ読めるようになる5つのコア単語セット（4択）：
* **📖 【英日】① 基本動詞（35問）**：`play`, `like`, `have`, `go`, `come`, `eat`, `see`, `make`, `study`, `use`, `want` など
* **📖 【英日】② 代名詞・疑問詞（33問）**：人称代名詞（`I-my-me-mine`, `you-your-you-yours`, `he-his-him-his`, `she-her-her-hers`, `we-our-us-ours`, `they-their-them-theirs`）の格変化穴埋め24問 ＋ `it`, `this`, `that`, `what`, `who`, `where`, `when`, `why`, `how` の英日9問
* **📖 【英日】③ 数字・曜日・月・季節（35問）**：`one`〜`twelve`, `Sunday`〜`Saturday`, `January`〜`December`, `spring`〜`winter`
* **📖 【英日】④ 超基本の形容詞（20問）**：`good`, `new`, `big`, `small`, `happy`, `busy`, `many`, `old` など
* **📖 【英日】⑤ 身の回りの名詞（30問）**：`school`, `friend`, `family`, `father`, `mother`, `teacher`, `book`, `pen`, `dog` など

### 文法穴埋めセット（『中学英語をもう一度ひとつひとつわかりやすく。改訂版』準拠・全21章）
各チャプター10問（計210問・2〜3択）。超基本単語のみを使ったシンプルな英文で、文法の核心だけを段階的にマスターできます。
* **✏️ Ch.01 主語と動詞とは・be動詞**（`am` / `are` / `is` の使い分け）
* **✏️ Ch.02 一般動詞**（一般動詞の基本・3人称単数現在の `-s` / `-es` / `has`）
* **✏️ Ch.03 品詞の基礎**（代名詞 `he/his/her`・形容詞・副詞の基礎）
* **✏️ Ch.04 否定文の基礎**（`am not` / `isn't` / `aren't` / `don't` / `doesn't`）
* **✏️ Ch.05 疑問文の基礎**（`Are you ~?` / `Do you ~?` / `Does he ~?` と答え方）
* **✏️ Ch.06 疑問詞**（`What` / `Who` / `Where` / `When` / `Why` / `How`）
* **✏️ Ch.07 複数形・命令文・代名詞**（複数形・命令文 `Don't` / `Let's`・目的格・所有代名詞）
* **✏️ Ch.08 現在進行形**（`be動詞＋~ing` の作り方・疑問文・否定文）
* **✏️ Ch.09 過去形・過去進行形**（`-ed`・不規則動詞・`did`・`was/were`・過去進行形）
* **✏️ Ch.10 未来の言い方**（`be going to` と `will`）
* **✏️ Ch.11 助動詞・have toなど**（`can` / `may` / `must` / `should` / `have to` / `don't have to`）
* **✏️ Ch.12 不定詞（基礎）・動名詞**（`to＋動詞の原形` の3用法・動名詞 `~ing`）
* **✏️ Ch.13 接続詞**（`that` / `when` / `if` / `because`）
* **✏️ Ch.14 いろいろな文型**（`There is/are`・`give 人 物`・`call A B`・`make A B`）
* **✏️ Ch.15 比較**（比較級 `-er/more`・最上級 `the -est/most`・`as ~ as`・`better/best`）
* **✏️ Ch.16 受け身**（受動態 `be動詞＋過去分詞`・`by ~`）
* **✏️ Ch.17 現在完了形**（`have/has＋過去分詞`・継続・経験・完了）
* **✏️ Ch.18 不定詞（発展）**（`It is ~ to ...`・疑問詞＋`to`・`want 人 to ~`・使役動詞 `let/make/help`）
* **✏️ Ch.19 後置修飾**（現在分詞 `~ing`・過去分詞による後ろからの修飾）
* **✏️ Ch.20 関係代名詞**（`who` / `which` / `that` の使い分け）
* **✏️ Ch.21 間接疑問文・仮定法**（間接疑問文の語順・`I wish` / `If I were you`）

## 🖥️ ローカルでの動作確認方法

GitHubに公開する前に、ご自身のPCや同一Wi-Fiのスマホから動作を確認できます。

### 方法1: ブラウザで直接開く（一番シンプル）
外部通信やサーバー機能を使っていないため、ファイルを直接ブラウザで開くだけで100%動作します。
* **ファイル**: `public/index.html`
* PCのファイルマネージャーから `index.html` をダブルクリック、またはブラウザにドラッグ＆ドロップしてください。
* （Linuxコマンドの場合: `xdg-open public/index.html`）

### 方法2: Pythonでローカルサーバーを起動（スマホ実機でも確認可能・推奨）
同一Wi-Fiに接続している娘さんのスマホから実機テストしたい場合に便利です。

1. **サーバーを起動**:
   ```bash
   cd public
   python3 -m http.server 8000
   ```
2. **PCから確認**:
   ブラウザで `http://localhost:8000` を開きます。
3. **同一Wi-Fiのスマホから確認**:
   * PCのローカルIPアドレスを確認します（ターミナルで `hostname -I` を実行）。
   * スマホのブラウザ（SafariやChrome）で `http://<PCのIPアドレス>:8000` を開きます。
   * 例: `http://192.168.1.15:8000`

## 🚀 GitHub Pages への公開手順

`public/` フォルダの内容を自動公開する GitHub Actions の設定を組み込み済みです。

### ステップ1: 変更のコミット
```bash
git add .
git commit -m "feat: setup speedspell app"
```

### ステップ2: GitHub でリポジトリを作成
1. ブラウザで [GitHub](https://github.com/) にログインし、右上の **「+」➔「New repository」** を開きます。
2. リポジトリ名を入力します（例: `speed-spell` または `anki`）。
3. 公開設定を **「Public」** に設定します。
4. チェックボックスはすべて外したまま、**「Create repository」** をクリックします。

### ステップ3: GitHub へプッシュ
```bash
# <YOUR_USERNAME> と <REPO_NAME> はご自身のものに置き換えてください
git remote add origin https://github.com/<YOUR_USERNAME>/<REPO_NAME>.git
git push -u origin main
```

### ステップ4: GitHub Pages の設定（Source を選択）
1. 作成したGitHubリポジトリのページで、上部メニューの **「Settings」**（歯車アイコン）をクリックします。
2. 左メニューの **「Pages」** をクリックします。
3. **「Build and deployment」** の下の **「Source」** ドロップダウンで **「GitHub Actions」** を選択します。
4. これでプッシュ時に自動的に `.github/workflows/deploy.yml` が走り、`public/` フォルダの内容が公開されます！
5. 数十秒で上部に公開URLが表示されます：
   ```
   Your site is live at https://<YOUR_USERNAME>.github.io/<REPO_NAME>/
   ```

## 📱 スマホで「本物のアプリ」として使う方法（ホーム画面追加）

本アプリは **PWA（Web App Manifest）** に対応しています。スマホのブラウザで公開URLを開き、ホーム画面に追加すると、アドレスバーのない全画面アプリとして起動できます。

### iPhone (Safari) の場合
1. Safari で GitHub Pages の URL を開きます。
2. 画面下部中央の **「共有ボタン（四角から矢印が出ているアイコン）」** をタップします。
3. メニューをスクロールし、**「ホーム画面に追加」** を選択します。
4. ホーム画面に稲妻アイコンの「SpeedSpell」が追加され、タップするとアプリとして起動します。

### Android (Chrome) の場合
1. Chrome で GitHub Pages の URL を開きます。
2. 画面右上または右下の **「メニュー（縦の3点リーダー）」** をタップします。
3. **「ホーム画面に追加」** または **「アプリをインストール」** をタップします。

アプリ右上の **歯車（⚙️）アイコン** をタップすると、新しい問題セットを追加できます。

### 一括貼り付けモード
テキストエリアに、学校のワークや教科書から単語を以下のように貼り付けるだけで完成します：

```text
pencil, 鉛筆
notebook, ノート
dictionary, 辞書
eraser, 消しゴム
textbook, 教科書
```

* カンマ区切りのテキストを貼るだけで、**トラップスペルや解説が自動生成**されます。
* 登録したセットはブラウザ内部（localStorage）に安全に保存されます。
